# Changelog

## 1.0.0 — 2026-10-12

First public NotRandom.org release, based on azate/anti-random.org.

- NotRandom.org name and custom icon.
- Toolbar popup and extension options with number and list tabs.
- Integer queue processed in insertion order, with range validation and one-use consumption.
- Locally displayed list results with configured values at the top in shuffled order.
- Original analytics integration removed; fonts bundled locally.
- Chrome Manifest V3 packaging.
- English documentation, privacy notes, and upstream attribution.
- Type-compatible list deletion handler and non-mutating development checks.
- Rebuilt from the supplied source with dependency license notices included.

The extension only changes local presentation, not RANDOM.ORG server-side results. Compatibility depends on the website's markup.
