**Расширение меняет только то, что отображается в вашем браузере. Оно не изменяет результаты на серверах RANDOM.ORG и не создаёт проверяемый результат.** Проект предназначен для демонстраций и изучения. Сообщайте зрителям и участникам о его использовании: скриншот или запись экрана могут показывать локально подменённый результат.

## Возможности

| Функция | Как работает |
| --- | --- |
| Очередь чисел | Целые числа используются в порядке добавления, по одному на успешную подмену. |
| Проверка диапазона | Первое число должно попадать между Min и Max. Иначе запускается обычный генератор, а очередь сохраняется. |
| Подмена списка | Заданные строки занимают первые позиции в случайном порядке; их порядок добавления не задаёт места. |
| Однократное использование списка | После подмены все заданные строки удаляются из настроек. |
| Управление значениями | Добавление, удаление отдельных значений и очистка вкладки. Повторяющиеся строки списка не принимаются. |
| Быстрый доступ | Одинаковый интерфейс в окне расширения на панели Chrome и в его параметрах. |
| Обычные клики | Левая кнопка запускает обычное поведение сайта, правая — локальную подмену. |
| Manifest V3 | Plasmo, React и TypeScript; шрифты включены в сборку. |
| Без встроенной аналитики | Интеграция аналитики исходного проекта удалена. |

## Установка в Chrome

1. Откройте [последний релиз](https://github.com/MrDemiurgen/NotRandom.org/releases/latest).
2. В разделе **Assets** скачайте **NotRandom.org-v1.0.0.zip**. Автоматические архивы **Source code** содержат исходники и не подходят для установки без сборки.
3. Распакуйте ZIP в постоянную папку.
4. Откройте `chrome://extensions` и включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
6. При желании закрепите NotRandom.org на панели Chrome через меню расширений.

Сохраните папку: Chrome загружает файлы из неё. Для обновления замените файлы новой сборкой, нажмите кнопку перезагрузки на карточке расширения и обновите страницу RANDOM.ORG.

## Использование

### Генератор чисел

Откройте NotRandom.org → **Random Number**. Введите целое число и нажмите **Enter** или кнопку **Add**. Повторите для нескольких чисел. На [RANDOM.ORG](https://www.random.org/) задайте **Min** и **Max** в блоке **True Random Number Generator**, затем нажмите **Generate правой кнопкой мыши**.

При очереди `7, 42` и диапазоне `1–100` последовательные правые клики покажут `7`, затем `42`. Если диапазон `10–100`, число `7` останется первым в очереди и сработает обычный генератор: расширение не перескакивает к `42`. Пустая очередь тоже запускает обычную генерацию.

### Перемешивание списка

Во вкладке **List Randomizer** добавьте нужные строки по одной. Введите исходный список на [странице перемешивания](https://www.random.org/lists/) и нажмите **Randomize** или **Again! правой кнопкой мыши**.

Заданные строки появятся в начале результата в случайном порядке, после чего все значения этой вкладки будут очищены. Для следующей демонстрации добавьте их заново. Используйте разные строки из исходного списка и не задавайте больше значений, чем в нём есть элементов. Расширение не проверяет наличие заданных строк в списке сайта.

## Конфиденциальность и разрешения

Расширение запрашивает **storage** и запускает скрипты только на HTTPS-страницах списков RANDOM.ORG и во фреймах виджета чисел. Собственной аналитики и сервера сбора данных нет.

Настройки сохраняются через `@plasmohq/storage`, по умолчанию в области **sync**: при включённой синхронизации Chrome значения могут синхронизироваться через аккаунт браузера. Обычные запросы к RANDOM.ORG продолжают выполняться; при перемешивании исходный список отправляется этому сервису. Подробнее: [PRIVACY.md](PRIVACY.md).

## Если не работает

- Обновите страницу RANDOM.ORG после установки или перезагрузки расширения.
- Используйте правую кнопку мыши.
- Проверьте, что первое число очереди входит в диапазон.
- После подмены списка добавьте строки заново.
- Изменения HTML на сайте могут нарушить работу расширения.
- Выполняйте по одной операции: одновременное использование в разных вкладках может дать неожиданный результат.
- Локальный результат не является независимым подтверждением честности розыгрыша.

[Сообщить об ошибке](https://github.com/MrDemiurgen/NotRandom.org/issues): укажите версию Chrome и расширения, адрес страницы и шаги воспроизведения. Удалите личные данные со скриншотов.

## Сборка из исходников

Нужны **Node.js 20** (`^20.10`) и **pnpm 8** (`^8.12`, закреплена версия `8.15.9`).

```sh
git clone https://github.com/MrDemiurgen/NotRandom.org.git
cd NotRandom.org
corepack enable
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm lint:check
```

Загрузите `build/chrome-mv3-prod` как распакованное расширение. ZIP также появится в `build`. Для разработки используйте `pnpm dev`. Перед распространением сборки добавьте тексты лицензий включённых зависимостей: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Правила участия и ручной проверки: [CONTRIBUTING.md](CONTRIBUTING.md). История изменений: [CHANGELOG.md](CHANGELOG.md).
